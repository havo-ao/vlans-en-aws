Cómo se hizo · paso 5

La API corre en Docker dentro de la subred privada

Terraform crea el servidor→ instala Docker al arrancar→ construye la imagen→ ejecuta el contenedor :8080

Dockerfile

FROM public.ecr.aws/docker/library/node:22-alpine WORKDIR /app COPY package.json . RUN npm install --omit=dev COPY . . EXPOSE 8080 CMD ["node", "server.js"]

Arranque del servidor (lo ejecuta AWS)

dnf install -y docker systemctl enable --now docker docker build -t reservas . docker run -d --name reservas \ --restart unless-stopped --network host \ -e DB_HOST=… -e DB_USER=… -e DB_PASS=… reservas

Salida real del servidor 10.0.11.235
