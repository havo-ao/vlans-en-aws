Dentro de AWS, sin SSH: Systems Manager

# ¿El equipo de pruebas alcanza el puerto de MySQL? $ aws ssm send-command --instance-ids i-082085c4973b11733 \ --document-name AWS-RunShellScript --parameters \ 'commands=["timeout 5 bash -c \"</dev/tcp/10.0.21.29/3306\" && echo ABIERTO || echo SIN RESPUESTA"]' $ aws ssm get-command-invocation --command-id … SIN RESPUESTA # La misma prueba desde el servidor de la API $ aws ssm send-command --instance-ids i-0a80b89ed1e9a6548 … ABIERTO

La red confirma cada intento

$ aws logs filter-log-events \ --log-group-name /vpc/vlans-flujo \ --filter-pattern '"10.0.21.29" "3306"' … 10.0.11.235 10.0.21.29 … 3306 … ACCEPT … 10.0.1.120 10.0.21.29 … 3306 … REJECT

Todo en un script: pruebas.py lanza los siete intentos, compara cada resultado con lo esperado y guarda resultados.json. Cualquiera puede repetirlo.
